# Current implementation

See the [README](../README.md) for current navigation and the [release notes](https://github.com/Shr1ramN/Dhara-Mitra_V1/releases) for shipped changes.

- Home and Calendar cover work, harvests, crop sales and worker records. Labour Management covers attendance, settlements, worker loans and reports.
- More manages farms, language and appearance, app lock, local backup and restore, and Excel or database export.
- The [earlier expanded plan](PLAN.md) covers modules such as weather, stock and farm finance. Some remain in the source and schema for compatibility, and historical records may appear in exports.
- Current GitHub APKs run in local mode. Cloud backup and private production signing are outside the current release.

See the [testing checklist](TESTING.md) and [security policy](../SECURITY.md).
