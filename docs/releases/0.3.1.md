# Dhara Mitra 0.3.1

- Fix unreadable heading/date colours in Light mode; explicit contrasting heading colours in both themes.
- Theme selection uses three buttons like language selection.
- Known generated calendar labels, attendance statuses and note units follow the selected language. User descriptions, names and custom crop text stay as entered.
- Add and retain custom work types alongside fertiliser, spray and irrigation suggestions.
- Sold to Buyer records any crop, buyer, quantity, bags/kg and exact income received. Income is separate from labour balances.
- Home shows crop-sale income, Calendar includes an Income filter, and Excel includes an Income sheet.
- Existing harvest, labour, financial and historical data retained; schema 6 unchanged. Sale entries do not imply automatic inventory reconciliation with earlier harvests.

Install over the existing app; do not uninstall or clear storage.
