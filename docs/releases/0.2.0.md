# Dhara Mitra 0.2.0 — simpler labour management

- Keeps the existing orange and green interface, Home / Calendar / More navigation, harvest lots and other farm tools. Less-used features remain under More.
- Opens the selected date's options immediately, including attendance, wage settlement, dues, labour reports, harvest, irrigation, fertiliser, spray and custom date notes.
- Adds workers from the worker list with a centred saved confirmation. New worker forms offer daily wages or a wage entered for each working day.
- Saves Present / Half day / Absent immediately. Daily half-day pay uses the configured half-day rate, or half the daily rate. For other workers, the entered amount is the actual day's pay, including half days. One shared daily work description is saved automatically.
- Adds previous/new worker loans, repayments and explicit deductions from wages. Historical advances keep their original wage-credit treatment and balances; they are not converted into new loans.
- Records weekly settlements, other date ranges, partial payments, payment dates, payment modes and loan deductions. A cancelled settlement reverses its wage credit and loan deduction together, allowing a corrected entry.
- Adds Labour Reports by week, month, year, custom range and worker. Earnings use work dates; payments use payment dates. Reports show attendance, paid wages, dues, loan movements, deductions and settlement history.
- Supports custom crops and labelled date notes. Harvest notes store bags or kg without assuming a conversion between them. These simple notes remain separate from the existing detailed harvest-lot workflow.
- Updates both English and Kannada text and checks narrow phone layouts with enlarged text.

## Updating an existing phone

Install **DharaMitra.apk** over the existing app. The package remains `in.dharamitra.app` and uses the existing signing certificate. Do not uninstall the old app or clear its storage. Exporting a backup first is recommended.

Schema 6 adds the worker wage type, worker loan entries and settlements. It preserves existing workers, attendance, full/half-day rates, historical piecework, payments, advance credits, farm profiles and attachments. Existing zero-day-rate workers become Other; existing daily-rate workers remain Daily wage. The database filename and profile catalogue do not change.

Regression coverage includes older schema upgrades, exact balances, repeated attendance taps, variable half-day amounts, partial settlements, duplicate settlement prevention, backdated loan repayment validation and backup/restore of linked loan deductions. English and Kannada widget checks cover 320px screens and enlarged text. Physical-phone acceptance is separate from these automated checks.

The APK retains the existing public development signing key for compatibility. It is not a new private-key production distribution.
